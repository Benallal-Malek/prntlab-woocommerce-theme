PRNTLAB 1.0.0 — тема WordPress

Установка:
1. Внешний вид → Темы → Добавить → Загрузить тему → prntlab.zip → Активировать.
2. Установить и активировать WooCommerce и Advanced Custom Fields с официальных сайтов.
3. Внешний вид → PRNTLAB → Загрузить демо. При необходимости включить рубли и назначение главной.
4. Установить prntlab-companion.zip для формы подписки (не обязателен для магазина).

Редактирование:
Главная: Страницы → Главная PRNTLAB → вкладки полей PRNTLAB.
Контакты и логотип: Внешний вид → Настроить.
Товары и размеры: Товары → нужный товар → Данные товара → Вариации.
Подписки: PRNTLAB подписки → экспорт подтверждённых адресов CSV.
Избранное: локально в браузере, до 48 товаров.

ACF Free / Pro. Repeater, Flexible Content и Options Page не требуются.
Без ACF сохранённое содержимое продолжает выводиться; для удобного редактирования нужен ACF.
Без WooCommerce тема выводит главную и обычные страницы; каталог требует WooCommerce.

В комплекте 7 локальных WebP-файлов. Импорт копирует их в медиатеку и создаёт 4 товара / 20 вариаций.
Цены, размеры, остатки, состав, преимущества и отзывы — демонстрационные данные.
Тексты о доставке и возврате, контакты и политика конфиденциальности требуют заполнения владельцем.
Перед приёмом заказов настройте валюту, доставку, налоги, способы оплаты и SMTP.
Полноценный HTML-код темы; изображение макета не используется как страница сайта.
