# PRNTLAB

A custom WordPress and WooCommerce theme for a hoodie store. The theme includes a responsive storefront and a demo importer so you can explore the shopping flow in a fresh WordPress installation.

![PRNTLAB theme preview](screenshot.png)

## Features

- WooCommerce catalog, product pages, and shopping cart.
- Variable products with size selection.
- Editable homepage sections through ACF.
- Demo importer with four products and twenty variations.

## Requirements

- WordPress 6.4 or later and PHP 8.0 or later.
- WooCommerce for the catalog and the demo importer.
- Advanced Custom Fields (Free or Pro) for editing the custom fields.

## Install the demo

1. In WordPress, go to **Appearance → Themes → Add New → Upload Theme** and upload `prntlab.zip`.
2. Activate PRNTLAB, WooCommerce, and ACF.
3. Go to **Appearance → PRNTLAB** and select **Загрузить демо** to import the sample catalog. Assign the demo homepage if this is a fresh installation.
4. Open the shop, choose a product and size, and add it to the cart.

See [readme.txt](readme.txt) for theme settings and the optional newsletter integration. The newsletter integration requires the separate companion plugin.
